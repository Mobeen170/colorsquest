# Coloriboo twilight music

`coloriboo_twilight_loop.wav` is an original 24-second music-box-and-warm-pad
loop generated by `tools/generate_coloriboo_audio/generate.py`. It is stereo,
16-bit PCM at 44.1 kHz and designed to join cleanly at its loop boundary.

The track remains optional at runtime. It starts only after explicit world
entry, plays quietly, and ducks while Boo speaks.
