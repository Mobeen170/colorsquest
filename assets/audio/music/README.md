# Music

Drop one properly licensed looping track here:

    coloriboo_dream_loop.mp3

It should be gentle, dreamy, music-box-like, quiet, and seamless when looped.

The file is **optional** — the app runs silently without it. When it is present
the music ducks automatically while Boo speaks, then fades back up.

Suggested sources: Pixabay, Mixkit.
